## Download

1. Open the [**latest release**](https://github.com/Sandipeyy/NikaMusicBeta/releases/latest).
2. Under **Assets**, download **`NikaMusic.apk`** (not the "Source code" links).
3. Open the file and install it. If Android asks, allow installs from your browser or file manager.

Requires Android 8.0 (API 26) or newer. If you already have an older Nika Music build with a different signature
or a higher version, uninstall it first.

## Features

Nika Music inherits its feature set from Echo Music:

- **Streaming and playback**: ad-free streaming, background playback, crossfade, data saver mode, audio and video switching
- **Offline**: download songs, albums and playlists with a built-in download manager
- **Lyrics**: synchronized lyrics with word-by-word timing, several animation styles and built-in translation
- **Discovery**: song recognition, smart recommendations, charts, podcasts, moods and genres
- **Customization**: Material You theming, dynamic colors, UI density, high refresh rate support, album-art options
- **Smart playback**: pause on mute, resume when Bluetooth headphones reconnect, sleep timer and more
- **Extras**: widgets, equalizer, listening stats (Wrapped), Discord presence, sharing through Song.link

Some features depend on third-party services and may change or stop working over time.

## What is different from Echo Music

- New name, new logo and new package ID: `nika.music.sandip`

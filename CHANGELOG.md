# Changelog

Every release needs a section here named after its tag. The release workflow copies that section
into the GitHub Release, and the app shows it as "What's new" when it finds an update.

## v1.0.0

First NikaMusic release, built on the latest Mochy Music: spatial Stage audio, floating lyrics, a module browser, Spotify canvases, better local-file import and many more languages.

### New
- New name, logo and icons, plus five custom launcher icons to pick from (Customise → Icons → Custom icon)
- **Recognize** tab: identify a song, see the result with cover art, and keep a history
- **Listen together**: open it, create or join a room, share the invite link or code, and listen in sync. Live members with pictures, host controls (including removing members), a shared queue guests can add to, and automatic reconnection
- **Song insights (optional AI):** explain what a song means, what it references, and suggest similar music; nothing is sent unless you tap
- **Share your bill:** the Wrapped receipt now has a Share button that sends it as a picture
- Song-recognition tile for Quick Settings
- Set any song as your ringtone from any song menu or the player menu, with a real trimmer for the part you want
- Six new home-screen widget styles: Modern Flow, Compact Glow, Showcase Card, Slim Strip, Vinyl Square and Vintage Turntable
- Updates now come from this repo: the app checks for new versions and installs them for you

### Changed
- The support prompt is simpler: no logo, no donate option; the donate page is gone
- New **liquid glass** floating navigation bar (Android 13+; lighter frosted look on older versions): real-time bending of what is behind it, light reflections, and a lens that follows the selected tab. Slide across the bar to change tabs
- The app now says NikaMusic everywhere instead of just "nika"
- Back button on the profile page
- Real Discord logo on the Discord card, and "meet the lead dev" is back on the About page
- Credits show GitHub profile pictures only, with a neutral placeholder when one can't be loaded
- Removed artwork and logos that belonged to other apps
- Cleaned up the About page and the profile page
- The icon picker's last family is now "Custom icon"
- The startup intro animation is off
